# 2026-05-27

## 修复音频转换挂起问题

**问题1**: FFmpeg worker 加载被 COEP 阻断。
- 原因: `routeRules` 仅作用于 Nitro 服务器，Vite dev server 不走 Nitro，导致静态资源无 COEP 头。
- 修复: 在 `nuxt.config.ts` 的 `vite.server.headers` 中添加 COOP/COEP/CORP 头。

**问题2**: 转换一直卡在"转换中"不结束。
- 原因: 使用的 `@ffmpeg/core-mt`（多线程版本）依赖 pthreads/SharedArrayBuffer，会派生子 worker，子 worker URL 在 Vite dev 环境下无法正确解析，导致 WASM 初始化永久挂起。
- 修复: 改用 `@ffmpeg/core`（单线程版本），无需 SharedArrayBuffer，无 pthread worker 派生问题。
  - `composables/useMediaConversion.ts`: 删除 `@ffmpeg/core-mt` 相关导入，改为 `@ffmpeg/core`，移除 `classWorkerURL` 参数。
  - 安装 `@ffmpeg/core@^0.12.6`。
