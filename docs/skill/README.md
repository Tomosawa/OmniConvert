# 📥 Skill安装指南

请在 Claude Code 对话中依次输入以下命令，即可完成安装：

1.  **安装 `superpowers`**：
    ```bash
    /plugin install superpowers@claude-plugins-official
    ```
    （此命令从 Claude Code 的官方插件市场安装）

2.  **安装 `frontend-design`**：
    ```bash
    /plugin install frontend-design@claude-plugins-official
    ```
    （此命令从 Claude Code 的官方插件市场安装）

3.  **安装 `Context7`**：
    ```bash
    /plugin install context7@claude-plugins-official
    ```
    （此命令从 Claude Code 的官方插件市场安装）

其它的技能已经内置下载好了放到 `.claude/skills` 里面了
